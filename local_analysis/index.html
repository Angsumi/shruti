01

Trinity assembly commands

Three retained launch scripts show successive local assembly configurations. The final “fix” script points directly to AZ1 normalized paired-end reads.

1.1 · Initial launcher

Normalized-read symlinks

The first script uses left.norm.fq and right.norm.fq, 8 CPUs, and 30 GB of memory. A second version raises this to 12 CPUs and 90 GB.

Initial script12-CPU script
1.2 · Path correction

Explicit AZ1 input files

The “fix” script removes broken normalization symlinks and uses AZ1 normalized read paths directly, with 12 CPUs and 120 GB. It requests --no_normalize_reads because the supplied reads are already normalized. No run log is retained to prove which launcher produced the saved statistics.

Fixed-path script

Assembly input scope

The final available Trinity launcher uses AZ1 read files only. Its output path is /home/angsuman/rna_pipeline/trinity_output/Trinity.fasta, outside this repository. The FASTA and run log are not retained here, so the exact assembly command behind the saved statistics cannot be confirmed.

What 68.0% means

BUSCO found 85 complete ortholog groups out of 125 in this selected lineage. It is a completeness benchmark for the local assembly; it does not establish expression differences among samples.

04

Salmon per-sample quantification

Scripts show intended indexing and quantification against the local Trinity FASTA. Original Salmon quant.sf outputs and logs are unavailable; six downstream count matrices and a 432-gene normalized expression subset have been recovered from GitHub.

4.1 · Build index

Index the local transcriptome

The manual script calls salmon index on Trinity.fasta with k-mer length 31 and 12 threads.

4.2 · Quantify three samples

Run paired-end reads through Salmon

It runs salmon quant separately for AZ1, AZ2, and AZ3 using trimmed paired-end FASTQs. Another orchestration script uses a three-sample file with one named library per sample; a separate monitor script quantifies normalized AZ1 reads only.

Manual Salmon scriptThree-sample orchestrationSingle-sample monitor

Recovered expression evidence

Six gene/isoform matrices retain rounded counts filtered to CPM > 1 in both samples of each pair. The CSV and TSV retain TMM-normalized values for a historically selected 432-gene subset. Original Salmon outputs and mapping-rate logs remain unavailable. Read the file guide · Open all expression downloads.

05

Full-assembly annotation script

The retained script describes TransDecoder and Trinotate on the local assembly. Its output database and report are absent from this folder.

5.1–5.3 · Prepare and predict

Build the annotation database

The script creates a Trinotate database, runs TransDecoder.LongOrfs and TransDecoder.Predict, then initializes Trinotate with the transcript FASTA, peptide FASTA, and gene-to-transcript map.

5.4–5.5 · Search and report

Run DIAMOND-enabled annotation

It requests Trinotate's --run ALL with --use_diamond and writes trinotate_annotation_report.xls to the external pipeline directory. That file is not retained here.

Evidence notes

Use the retained numbers with their source assembly and keep command intent separate from observed output.

Local FASTA is missing

The statistics and BUSCO file both refer to /home/angsuman/rna_pipeline/trinity_output/Trinity.fasta. That FASTA is not in this repository, so its sequences cannot be rechecked here.

Different from the vendor assembly

Local TrinityStats reports 2,944,151 transcripts and 1.07 Gbp; the vendor FASTA has 318,934 sequences and 149.46 Mbp. They must be treated as separate assembly outputs.

Execution history is incomplete

Multiple assembly and downstream launchers remain, but their logs are absent. The exact launcher behind the retained statistics cannot be established from these files.

No DEA result

No control/treatment design is recorded. Recovered historical expression subsets are retained as numerical evidence; this page reports no differential-expression findings.
