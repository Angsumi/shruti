  • Sample ID: Sample name

  • Phred Score: The measure of base quality of the sequencing data
  • Q30 score: The percentage of bases with higher Phred score than 30 in total bases
  • Data size(GB): The size of original sequence data in giga base pairs

3. DeNovo Assembly

De novo transcriptome assembly is the de novo sequence assembly method of creating a transcriptome without the aid of a reference genome. The Trinity tool represents a novel method for the efficient and robust de novo reconstruction of transcriptomes from RNA-seq data.

4. Structural and Functional Annotation

Trinotate is a comprehensive annotation suite designed for automatic functional annotation of transcriptomes, from model or non-model organisms. Trinotate makes use of a number of different well methods for functional annotation including homology search to known sequence data (BLAST+/SwissProt), protein domain identification (HMMER/PFAM), and leveraging various annotation databases (eggNOG/GO/Kegg databases).

4. Variant Calling

Single nucleotide polymorphism (SNP) refers to a variation in a single nucleotide which may occur at some specific position in the genome, including transition and transversion of a single nucleotide. We detected the individual SNP variations using freeBayes with the following parameter.

To reduce the error rate in SNP detection, we filtered the results with the criterion as follows:

  • The filtered depth (DP) for each SNP should be more than 30
  • The mapping quality of each SNP should be higher than 30
